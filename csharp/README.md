RPG Combat Approval Kata in C#
==============================

This code has an implementation for this kata, but it may or may not work since there is only very sketchy test coverage. 

1) Add tests for different kinds of scenarios. Refer to the exercise description [RPG Combat](https://sammancoaching.org/kata_descriptions/rpg_combat.html). Focus on the first three user stories - "Damage and Health", "Levels" and "Factions". Do not read the code, only focus on making readable tests for important scenarios.


2) Activate each of the 6 bugs in turn:

There is a public static field "BugId" in PlayerCharacter. If you set it to a value between 1 and 6 a bug will appear in the implementation.

Write a note of what each bug is, based on any test failures you find. Try to diagnose the problem purely from the test failure information, do not read the code.
